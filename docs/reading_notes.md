# 文献四栏表（Reading Notes）

> 每读一篇论文，**强制**填一行。目标是让"可攻击点"这一栏积累成选题金矿。
> 用法建议：也可以用 Zotero + Excel/Notion 维护，这里留一份纯文本记录。

## 使用说明

| 栏目 | 填什么 |
|---|---|
| 论文 | 作者+年份+期刊，或简写 |
| 要解决的问题 | 一句话说清它想解决什么 |
| 核心机制 | 它提出的新机制/新策略是什么 |
| 实验设计 | 基准集、维度、对比算法数量、独立运行次数、有无统计检验/消融 |
| **可攻击点** | 它的缺陷、没做的事、能被改进的地方 ← **最重要** |
